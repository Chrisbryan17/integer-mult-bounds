# Divide-and-conquer follow-up: P104 signed mixed-carrier bank

**Scope:** independent finite geometry, abstract paid-rank analysis, conditional selected-frontier moment test, and an explicitly unproved native/all-size implementation. **No new κ or completed native supplier is claimed.** This follow-up accompanies PR #2844 and does not modify the selected frontier.

## Gate A — entire P104 E8 decoder family

An independently reconstructed E8 frame-pair census checked **7,168** P104 decoders, **2,408,448** signed pair-read eligibility incidences, and a 104×104 exact signed integer matrix for one decoder. Every cube edge provides a legal **binary rank-two frame** U_ij=span(u_i,u_j) inside a target sink when both terms are required. This is a geometric inclusion claim, not proof of a physical scalar ADD/phase implementation.

**Affine root shortcut obstruction:** For every one of the 86,016 decoder-edge instances, the signed root-vector combination c=a_i-s a_j is an existing *live* E8 root but its binary label is u_c=u_i+u_j+z, with the **same affine parity direction z** in every case. For target sinks requiring both terms, z is excluded. Under the model requiring a target path to visit the root label before terminating at the sink, the target costs at least **two excess frame rank units**. The eight-edge, 16-helper bank uses such a pair on 100 distinct target paths, hence a root-only detour incurs **at least 200 extra units** in that restricted interface. This does not preclude a shared parity adapter or a general rank-two frame compiler.
