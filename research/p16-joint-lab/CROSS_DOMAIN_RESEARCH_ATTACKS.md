## Source-backed avenues (ranked)

**1. Multisource amortized transform synthesis.** David Harvey's 2026-10-20 technical note, https://web.maths.unsw.edu.au/~davidharvey/research/subnlogn.pdf, explains why efficiency on W independent butterfly tensors can amplify into an exponent saving even if the isolated single-array transform is not faster. Maintain the exact W-input/W-output linear map (no correlated inputs); meter all new helper owners and shared data movement. This escapes the current 408-helper count and 16-pair controller family. Research hypothesis only, not a theorem about new W-gadget.

**2. Laurent-gauge and lifting synthesis.** Daubechies--Sweldens, https://sites.math.duke.edu/~ingrid/publications/J_Four_Anal_Appl_4_p247.pdf, prove elementary Laurent lifting factorizations for the classical 2x2 wavelet/polyphase setting. The 32x32 P16 controller is a different multivariate object: do not assume 2x2 lifting results apply without a new factorization theorem. Search exact replacement shears in the Laurent group ring, jointly pricing idle transforms and unit/nonunit scalar coefficients. The 154-event PR4470 schedule has been independently source-serialized and pinned by SHA-256 to the selected GitHub fixture. The exact gauge diagnostic finds **62 of 90** ADDs acquire nonunit Laurent weights if all 15 idle events are dematerialized as tags; seven native operations also see pending tags; 28 output registers retain tags. Thus *tagging alone is not free* and requires an algebraically equivalent re-synthesis.

**3. Owner-aware reversible pebbling.** The reversible pebbling SAT literature, https://arxiv.org/abs/1904.02121, and https://github.com/MassimoLauria/pebble allow exact storage/recomputation tradeoffs on dependency DAGs. Embed native owner, helper-liveness, erase and two-orientation constraints. Search for genuine productive reuse of a rank-64 idle obligation, with all new moves priced. This is not equivalent to a free CPU-memory compiler: physical rank child semantics matter.

**4. Clifford min-cost SAT and lower bounds.** Q-Synth https://github.com/irfansha/Q-Synth can exactly optimize small Clifford circuits for CNOT count/depth. The LMC bound https://arxiv.org/abs/2609.16208 can lower-bound restricted CNOT syntheses. Adapt gate sets to Gaussian C(q,±), X/P/D/PH with **absolute global phase** and rank-r native child prices, then run controlled windows of the exact E8 supplier. Q-Synth's quantum-specific cost function must not be mistaken for our recursive paid rank moment.

**5. Structured multi-bottleneck optimization.** Reza Zadeh, https://arxiv.org/html/2610.10593v1, obtained an improved matrix multiplication exponent with mass-conditioned optimization and explicit correction of several simultaneous bottlenecks; this is a methodological parallel, not a reusable integer multiplication exponent. Jointly optimize the actual selected complex moment, BIT moment, owner feasible set, tape/idle penalties and output independence rather than one native statistic.

**6. Equality saturation and in-place transform compilation.** https://github.com/egraphs-good/egg provides exact equivalence-class representation/extraction machinery. Treat Laurent factorization identities as rewrite rules and use certified extraction with resource state. Harvey--Roche's in-place truncated FFT https://arxiv.org/html/1001.5272v1 demonstrates real space/time trade-offs. For our Turing implementation, prove physical tape locality; do not count abstract RAM permutations as free.

**7. External clean execution oracle.** https://github.com/Klakocik/below-nlogn provides small-gadget experimental Rust tests for the original OpenAI manuscript, explicitly not the impossible-scale whole multiplier. Use it for independent motif/source-shear regression, not a claimed record.
