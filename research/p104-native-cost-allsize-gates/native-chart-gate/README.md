# One real E8 decoder: emitted native Clifford charts and exact signed replay

**Status:** finite construction and phase-checked explicit canonical chart recipes. **Not a supplier, a validated whole native compiler, a new κ, or an all-size integer multiplier.** Checked on 2026-10-16 with the local isolated Python 3.13 runtime, using the root decoder and prior package independently reconstructed from merged predecessor #1125 and the PR #2844 schematic. GPT-6 assisted. Apache-2.0.

## New executable work

- `native_chart_emitter.py` reconstructs the real 120-root E8 labeling, selects an F2^9 coordinate chart, uses **actual root labels** and target hyperplane sinks (no synthetic cube chart at the transport gate), and emits every common-chart signed ADD and every nested frame move. For each move it writes an explicit Clifford word in the publisher's gate alphabet `P(G), D(Q,alpha), C(q,±)`: `Gamma(new) Gamma(old)^(-1)`, where `Gamma(U)` uses the source's canonical Gaussian-diagonal address chart. **These are not the optimized one-child rank-difference recipes** in the selected supplier.
- `verify_native_chart_word.py` independently replays **1,064 chronological events**, checks the signed transfer for all **104 output rows**, checks that arbitrary preexisting Y data is preserved, and that all eight clean initialized helpers return to exact zero. Five corruptions of sign, ADD, rank, gate phase, and initialization are rejected. **A deliberately dirty initial helper contaminates 22 outputs**. Full dirty-helper support is absent.
- `verify_phase_exact.py` has a separate integer/Gaussian-amplitude kernel for the nine-axis Clifford primitives. It checks all **514 native recipe/reverse loops** on a literal basis vector, another 30 boundary probes, and rejects a changed global phase and an altered signed C child. These test the literal phase consistency, not independent equality to the publisher's chosen original hardware chart convention. Chart equality is by definition of the emitted Gamma and must still be bound to an accepted higher-level native supplier.
- `native_invoice.py` repeats **both** the source-only and mixed traces under the *same* canonical chart-emitter rules and records every C gate and abstract frame rank. The comparator is the restricted home-return baseline, not the best selected supplier.

The mixed `4,160` is a direct decomposition of all stored chart transitions into C gates. It is **2,664 greater** than the abstract rank-1,496 proxy. It does not imply 4,160 optimized recursive children are unavoidable; published rank-difference factorization might drastically improve it. Conversely, the abstract rank-1,496 cannot be claimed as the true paid native invoice until those factors are *emitted and checked for each occurrence*.

## Closed gates / open next work

1. **Passed:** exact 9D root-label frame incidence for a full E8 signed decoder; all 104 symbolic outputs and arbitrary Y inputs; eight *clean* helper zero restorations; literal signed Clifford recipe inverse-phase checks.
2. **Explicitly failed:** allow arbitrary dirty helper initialization. A single dirty helper contaminates 22 outputs. Any valid physical supplier must **provide and pay for** clean helpers or redesign the mixer to cancel arbitrary dirt at every target.
3. **Still open:** native rank-optimal transport factorization; source access / endpoint adapters / physical inverse-transpose; arbitrary dirt or clean allocation cost and ownership; optimized head-to-head comparator; exact selected recursive child histogram and both moment engines; every uniform all-size and analytic/rounding obligation.

### Reproduce

From this directory: `python3 -I -B verify_native_gate.py` (Python 3.10+, standard library). The emitted large JSON can be regenerated, or supplied as `evidence/NATIVE_CHART_WORD.json.gz`. Vendor source pins from the earlier package remain intact. It does not alter `upstream/`, selected κ `0.001672660197076918`, or any accepted certificate.
