# Cao P16 physical rank-2 pair-fusion search

Search the frozen Cao #4610 native word for a real `F2 + F2 -> F1 + F3` **shared scalar-contact** transformation. This hypothetical rank-mass-neutral exchange would increase the full P16 productive-minus-paid moment at κ=0.0030217758, but only an exact all-operand GF(2) frame and complete native/phase/owner invoice could count as a circuit win.

`f2_pair_fusion_search.py` reconstructs the entire frozen 21,449-event source word; strips charged climb markers for regeneration; walks each L-role's exact preceding and following scalar or native-warp frame in chronology; and finds each scalar contact whose old midpoint has paid rank 2 before and after on a persistent role. It computes the **linear span** of all preceding operand charts and the **intersection** of all following operand charts, enumerating exact one-axis reductions of the original shared contact frame inside this legal interval. It then prices changes with `r^(1-κ)` and, if any are favorable, resynthesizes both native programs, compares their *actual complete* paid invoices and demands all 632 independent columns in both orientations.

**Dell result:** 59 contacts have some L-role with paid F2 before and F2 after. All 59 joint GF(2) feasibility intervals are checked; **no cheaper rank-one-middle shared frame passes the full operand constraints**. Therefore no candidate was promoted to dual replay, and no new κ was found in this restricted family.

This does **not** rule out two-child fusion across several scalar contacts, different native G maps, helper entrance changes, changed scalar DAG, controller factorization or new coupled native primitive. Those are separate harder targets. In particular, raw 2*2^t-1^t-3^t positivity is only a hypothetical histogram until an exact physical word exists.

Run `python -I -B research/p16-cao-paid-fusion/f2_pair_fusion_search.py /path/to/frozen-repo`.
