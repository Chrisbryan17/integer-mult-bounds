A constructive Bruhat factorization produces a P,D,C word with rank-many C operations at the symplectic level. Explicit Clifford sign flips and Pauli/PH adjustments correct **integer Gaussian phase**. Exactly 168 of 756 realized uses require an additional pair `C(q,+)^2 = X_q`, giving `1496 + 2*168 = 1832` C occurrences. The distinct-recipe sum of abstract ranks is 1185; occurrence-weighted rank sum is 1496.

The current construction still requires eight actually-clean auxiliary registers, and a dirty initial helper provably contaminates outputs. No helper allocation, `P`, `D`, `PH`, source address, scalar ADD, host, tape, precision or inverse-transpose is assumed free by the theorem. The equal-treatment unmixed chart trace is **not** the optimized published #1094 supplier.
