# Cao Yifan P16 research: targeted, frozen source archive

This **source-only snapshot** was assembled from Git directory objects of
`CrocSwap/integer-mult-bounds` at exact frozen commit:

`20bb93cd990d2ff683e4d0fc56b87a42cd5d3296` (Cao Yifan #4610).

It is intentionally **not** the entire 2.45 GB repository. Every copied
directory is referenced by its original upstream Git tree SHA, preserving
every file, native witness, gzip payload and proof/source byte in those
directories without reconstruction or modification.

## Included
- Frozen 21,449-event forward/backward native witness:
  `research/kappa-round3-warp-20261022/ACTUAL-WORD.json.gz`.
- Native identity, absolute-phase and 632-column verification tools;
  warp-interface, helper-frame geometry, exact Clifford operations and
  source-bound operator replayers.
- Whole P16 16-pair controller, ordinary BIT conversion, dual exact
  rational moment computations, critical-root compiler and outer guards.
- Cao's round-three Lean proof package and round-six compiler tightening.
- Relevant depth-specific inherited source dependencies, but not the
  entire research history, old experiments, unrelated 2+ GB certificates.

## Reproduction
The extraction preserves upstream paths. Run the source scripts from
the archive root with their documented Python versions. Some deep,
historically inherited proof obligations may require extra upstream
source files not included here; this archive prioritizes the *active P16
native/cost research*, not a claim of fully vendored all-era tests.

The original canonical 21,449-event native payload SHA256 is
`cfcd36b40326d7a5815e1db5313444379b3fb756b27d5201c561574c085cc0dd`.
